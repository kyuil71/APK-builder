# AI Road Guardian · 연구·시험용 (네이티브 Android)

갤럭시 Z 폴드8 울트라 후면 카메라로 **차량·보행자·자전거·오토바이·차선**을 폰 안에서 실시간 인식하고,
내 차선에서 **지금 브레이크를 밟지 않으면 제때 못 멈추게 되는 대상**이 있을 때만 경고합니다.
인터넷 권한이 없으며, AI 모델은 APK 안에 들어 있습니다.

> ⚠️ 실제 도로에서 검증된 충돌 방지 장치가 아닙니다. 차량의 안전장치와 운전자의 판단을 대신하지 않습니다.
> 먼저 앱의 **영상 시험**으로 녹화된 주행 영상에서, 또는 통제된 환경에서 시험하세요.

## 설치
1. 이 저장소의 **Releases**에서 `AI Road Guardian v0.1.N (시험용)`을 엽니다.
2. `RoadGuardian.apk`를 눌러 내려받고 설치합니다. 처음 한 번은 '출처를 알 수 없는 앱 설치'를 허용하세요.
3. 앱을 열고 안내에 동의 → 카메라·위치 권한 허용.
4. 폰을 **세로로**, 차 폭의 가운데쯤, 카메라가 도로 정면을 보게 고정합니다.
5. **설정**에서 폰 높이(지면→폰)와 보닛 길이(폰→앞범퍼)를 맞춥니다.

## 설치할 때 보안 경고가 뜨면
"잠재적으로 유해한 앱 감지됨" 같은 경고는 **Play 스토어 밖에서 받은, 개발자가 알려지지 않은 앱**에 대해 폰의 보안 기능이 보여 주는 것입니다.
이 앱은 이 저장소의 공개 소스로 GitHub에서 직접 빌드한 것이고, 인터넷 권한이 없습니다.
- 경고 창에서 **닫기** → 앱을 다시 실행해 봅니다 (경고만 뜨고 실행되는 경우가 많습니다).
- 설치 단계에서 막히면: 설치 경고의 **세부정보 더보기 → 무시하고 설치**.
- 그래도 막히면 잠시만: Play 스토어 › 프로필 › Play 프로텍트 › 설정 › **'Play 프로텍트로 앱 검사'** 끄기, 삼성 설정 › 보안 및 개인정보 보호 › **자동 차단기** 끄기 → 설치·실행 → **다시 켜기**.
- v0.1.5부터 정식(릴리스) 빌드 + 전용 서명 키입니다. 이전 버전이 깔려 있으면 먼저 삭제하고 설치하세요.

## 화면
| 위치 | 내용 |
|---|---|
| 카메라 | 내 진로(차선 사이, 커브를 따라 휨), 인식한 차선(실선)·추정 차선(점선), 차선 도색 점, 진행 방향 화살표, 제동 한계선(빨간 선), 인식 박스(분류·신뢰도 %·거리 범위) |
| 오른쪽 위 | 위험 단계 — **회색 판단 불가 · 초록 징후 없음 · 노랑 주의 · 빨강 위험** + 한 줄 설명 |
| 오른쪽 가운데 | 위에서 본 지도: 내 차, 진로, 차선, 주변 물체, 3초 뒤 예상 위치 |
| 아래 버튼 | 렌즈(자동/광각/망원) · 경고음 ON/OFF · 영상 시험 · 설정 |
| 위험 시 | 화면 전체가 빨갛게 + 방향 화살표 + 경고음 + 음성("전방 차량, 브레이크") + 진동 |

## 판단 방식
- **판단 불가(회색)**: AI 모델 미준비·오류, 프레임 1.2초 이상 정지, 처리 650ms 초과, 영상이 너무 어둡거나 가려짐, 렌즈 전환 중, 기울기 센서 없음. *실패를 안전으로 표시하지 않습니다.*
- **진로**: 차선을 인식하면 차선 사이, 못 하면 자이로 회전으로 추정한 진로(설정한 차선 폭).
- **접근 속도**: 거리 변화 + 영상 속 크기 변화율(카메라 보정값과 무관)을 합칩니다. 보행자·자전거는 내 진행 방향으로 낼 수 있는 최대 속도를 감안합니다.
- **빨간 경고**: 진로 안(또는 끼어들기·횡단으로 들어올 예정)이고, 남은 거리 ≤ 접근속도×반응시간 + 접근속도²/(2×급제동 한계) + 2m.
- **주의**: 여유 있게 미리 (반응 +1.2초, 3.5m/s² 기준). 대상마다 한 번만 알림.
- **경고하지 않음**: 진로 밖(옆 차선·갓길·마주 오는 차·인도), 멀어지거나 같은 속도의 앞차, 15km/h 이하 서행 중 앞차 접근, 정차 중.
- **숫자 표시**: 거리는 `약 30~45m`처럼 범위로만(불확실하면 '거리 불확실'), TTC는 크기 변화율이 안정적일 때만 0.5초 단위.

## 대시보드 오인식 방지 (차 내부 가림)
화면 아래쪽 대시보드·보닛을 '차량'으로 잘못 인식하지 않도록, 차 내부 영역을 분석에서 뺍니다 (화면에 어둡게, 주황 점선으로 표시).
1. **보닛 계산 (바로 적용)**: 폰 높이·보닛 길이로 보닛 끝이 화면에서 지나가는 높이를 계산. 그보다 아래 노면은 보닛에 가려 보일 수 없으므로, 박스의 75% 이상이 그 아래에 있는 물체는 차 안의 물체로 보고 버립니다.
2. **주행 중 학습 (몇 초)**: 달리는 동안 도로는 흘러가지만 대시보드는 화면에서 움직이지 않습니다. 열마다 아래에서부터 '움직이지 않는 영역'을 찾아 가림선을 맞춥니다 (12m 앞 노면보다 위로는 올라가지 않음, 정차 중에는 학습 안 함).
3. **수동**: 설정 › 대시보드 가림 % 로 화면 아래를 직접 지정.

가림선 아래로 일부가 가려진 실제 앞차는 버리지 않고, 바닥 접점 대신 크기로 거리를 잽니다.

## 자동 보정
- **카메라 화각**: 카메라 초점거리·센서 크기로 자동 계산 (설정에서 직접 지정 가능)
- **카메라 기울기**: 중력 센서 + 수동 보정 + 차선 기반 자동 보정
  (영상 속 두 차선의 소실점 → 큰 오차, 두 차선의 평행성 → 미세 오차. 커브를 도는 중에는 자이로 기준으로 쉼)
- **망원**: 렌즈 '자동'이면 55km/h 이상에서 3배 망원(원거리 약 100m), 45km/h 미만에서 광각. 고속·망원일 때는 수평선 주변을 원본 해상도로 잘라 한 번 더 감지

## 녹화 영상 시험
**영상 시험** → 갤러리에서 주행 영상 선택 → 0.1초 간격으로 분석. 영상에는 센서·GPS가 없으므로
설정의 *녹화 영상 속 주행 속도 / 카메라 기울기 / 화각*을 씁니다 (차선이 보이면 기울기는 자동 보정).

## 구성
| 파일 | 내용 |
|---|---|
| `core/Core.kt` | 판단 엔진(안드로이드 의존성 없음): 차선 검출·피팅·소실점, 거리, 추적, 위험 판단, 판단 불가 규칙, 경고 정책 |
| `core/YoloPost.kt` | YOLOv8 출력 해석(1×84×8400 / 전치), NMS |
| `YoloDetector.kt` | ONNX Runtime 온디바이스 추론 (XNNPACK → CPU) |
| `Engine.kt` | 프레임 처리: 차선 → 감지(+원거리 확대) → 추적 → 판단 → 경고 |
| `MainActivity.kt` | CameraX, 센서, GPS, 렌즈, 녹화 영상 시험, 소리·음성·진동, 화면, 설정 |
| `Views.kt` | 카메라 오버레이, 위에서 본 지도 |
| `tests/CoreTest.kt` | PC 테스트: 판단 시나리오 30개, 판단 불가 7개, 경고 정책 4개, 추적, YOLO 해석, 달리는 합성 도로 9가지 |

## 빌드
GitHub Actions(`.github/workflows/road-guardian.yml`)가 `road-guardian/` 변경 시 자동 빌드합니다.
모델(COCO 사전학습 YOLOv8n, 640×640 ONNX)은 빌드 때 내려받아 APK에 넣습니다.
PC에서: Android Studio로 `road-guardian` 폴더 열기 → 모델을 `app/src/main/assets/yolov8n.onnx`에 두고 → `assembleDebug`.

## 한계
- 실기기·실제 도로 검증 전입니다. 처리 속도(FPS), 발열, 망원 렌즈 실제 전환 여부는 폰에서 확인이 필요합니다.
- 비·눈·야간·지워진 차선에서는 차선 인식이 약해집니다(그때는 회전 기반 진로 추정).
- 앞차의 급감속(가속도)은 따로 예측하지 않고 거리 변화로 판단합니다.
- **라이선스**: YOLOv8(Ultralytics) 모델은 AGPL-3.0입니다. 개인 시험용은 괜찮지만 배포·상업적 사용 전에는 검토가 필요합니다.
